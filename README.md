# 🍗 Catálogo Sencillo

Catálogo web simple para una rotisería, pensado **para usarse desde el celular**: muestra los productos del local con su descripción y precio, de forma clara y fácil de recorrer con el dedo.

## ✨ Características

- Diseño pensado para celulares (*mobile first*)
- Listado de productos con nombre, descripción y precio
- Botones y textos grandes, fáciles de tocar y leer
- Fácil de actualizar: no requiere base de datos ni servidor
- Ideal para compartir el link por WhatsApp o redes sociales

## 🛠️ Tecnologías

- HTML
- CSS
- JavaScript
